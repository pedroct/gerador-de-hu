# Convenções deste projeto

## Idioma

Todo o conteúdo criado neste projeto — `SKILL.md`, referências, specs de design, planos de
implementação, README, comentários e mensagens de commit quando fizer sentido — deve ser escrito em
**português brasileiro**, nunca em inglês.

Isso vale mesmo quando uma skill de processo (ex.: `writing-plans`, `brainstorming`) fornecer um
template com rótulos em inglês (`Goal`, `Architecture`, `Files`, `Step N`, etc.): traduza a prosa para
pt-BR. Traduza também os rótulos estruturais, a menos que uma skill de execução downstream (ex.:
`executing-plans`, `subagent-driven-development`) dependa literalmente da palavra em inglês para
localizar a seção — nesse caso, confirme com o usuário antes de renomear.
